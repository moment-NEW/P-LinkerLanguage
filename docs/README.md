# P-LinkerLanguage 文档

P-LinkerLanguage 用普通 C 结构体描述嵌入式链接布局，再生成 GNU ld 或 Arm Compiler 6 scatter 文件。业务代码通过少量宏把函数或初始化条目放入逻辑区域，并通过稳定的 C 符号读取区域边界。

本项目目前是一个经过两种工具链验证的 demo，不是完整的链接脚本替代品。它覆盖自动初始化、RAM 执行代码、固定保留内存三类场景。芯片启动文件、向量表、常规 `.text` / `.data` / `.bss`、堆和栈通常仍由原工程链接脚本负责。

## 推荐阅读顺序

1. [01-链接基础](01-链接基础.md)：不了解 Flash、RAM、section、符号时先读这里。
2. [02-五分钟入门](02-五分钟入门.md)：复制现有 demo，生成并验证第一个区域。
3. [03-布局描述语言](03-布局描述语言.md)：理解 `pl_memory_t`、`pl_link_region_t` 与所有字段。
4. [04-业务代码接口](04-业务代码接口.md)：使用 `PL_INIT`、`PL_RAMFUNC` 和生成的边界符号。
5. [05-构建与工具链](05-构建与工具链.md)：接入 GNU Arm 和 ARMClang 工程。
6. [06-生成器原理](06-生成器原理.md)：了解条件编译筛选、正则词法和受控 C 解析边界。
7. [07-排错与验证](07-排错与验证.md)：排查构建、链接、复制和初始化顺序问题。
8. [08-扩展路线](08-扩展路线.md)：在当前模型上增加新区域类型与校验。

## 最小工作流

```text
layout.pl.c
    -> Python 读取结构体布局
    -> 生成 .ld 或 .sct，以及 pl_linker_symbols.h
    -> 编译业务 C 代码
    -> 链接器收集输入 section 并导出边界符号
    -> 启动代码复制 RAM 区域、遍历初始化表
```

## 仓库导航

| 路径 | 用途 |
| --- | --- |
| `inc/pl_linker_layout.h` | 布局描述的 C 类型和辅助宏。 |
| `inc/pl_linker.h` | 业务代码注册初始化函数与 RAM 函数的宏。 |
| `tools/generate_linker.py` | 条件筛选、词法、解析、验证和后端生成器。 |
| `example/layout.pl.c` | 完整布局示例。 |
| `example/main.c` | 初始化遍历与 RAM 代码复制示例。 |
| `build/` | 生成文件和验证产物；默认不提交。 |

| 能力 | 状态 |
