# 链接基础

本章只解释使用本库时必须理解的概念。目标是能看懂布局文件，不要求预先掌握 GNU ld 或 scatter 文件语法。

## 1. 固件不只有一段代码

MCU 上通常至少有两块内存：

| 内存 | 常见用途 | 典型特点 |
| --- | --- | --- |
| Flash | 固件映像、常量、默认程序代码 | 断电不丢失，写入慢，通常可直接取指执行。 |
| RAM | 变量、堆栈、快速执行代码 | 断电丢失，读写快，容量较小。 |

编译器把每个 `.c` 文件编译为目标文件。目标文件里的函数、常量和变量会落在很多**输入 section** 中，例如 `.text`、`.rodata`、`.bss`。链接器再将输入 section 合并成最终固件中的**输出 section**，并决定其地址。

P-LinkerLanguage 的 `pl_link_region_t` 描述的是输出 section 或 Arm Compiler 的 execution region。

## 2. 输入 section 与输出区域

以自动初始化为例：

```c
PL_INIT(app_init, 010, clock_init);
```

这行 C 代码会创建一个函数指针对象，并把对象放入输入 section：

```text
.pl.init.app_init.010
```

布局对象的 `.name = "app_init"`、`.type = PL_LINK_INIT` 告诉生成器：链接时收集所有匹配下面模式的输入 section：

```text
.pl.init.app_init.*
```

最终输出区域名为 `.pl.app_init`，它的起点和终点以 `pl_app_init_start`、`pl_app_init_end` 导出。

## 3. 地址、大小和对齐

一个区域有以下三个关键属性：

- **地址**：区域从哪里开始。
- **大小**：区域占多少字节。
- **对齐**：区域起点必须是某个数的整数倍。

例如：

```c
.address = 0x2001E000,
.size = PL_KIB(8),
.alignment = 32,
```

表示起点为 `0x2001E000`，大小是 $8 \times 1024 = 8192$ 字节，终点为：

$$
0x2001E000 + 0x2000 = 0x20020000
$$

`32` 字节对齐意味着起点必须能被 32 整除。当前生成器要求对齐值是非零的 2 的幂，例如 1、2、4、8、16、32。

## 4. 运行地址和加载地址

普通 Flash 代码只有一个重要地址：它在 Flash 中存放并执行。

RAM 执行代码有两个地址：

| 名称 | 缩写 | 含义 |
| --- | --- | --- |
| 运行地址 | VMA | CPU 真正取指执行的地址。 |
| 加载地址 | LMA | 固件镜像中该代码最初存放的地址。 |

例如 `PL_LINK_RAM_CODE`：

```text
Flash LMA: 0x08000044  -> 固件烧录后机器码所在位置
RAM VMA:   0x20000000  -> 复制完成后函数执行位置
```

启动代码必须在调用函数前，把 `[load_start, load_start + size)` 拷贝到 `[start, end)`。

## 5. 链接符号不是 C 变量

布局中的：

```c
.start_symbol = PL_SYMBOL(pl_fast_code_start),
.end_symbol = PL_SYMBOL(pl_fast_code_end),
```

不会定义可写 C 变量。它们是链接器提供的地址标签。生成头文件将其声明为数组：

```c
extern uint8_t pl_fast_code_start[];
extern uint8_t pl_fast_code_end[];
```

数组名在表达式中会退化为地址，因此可这样计算长度：

```c
size_t size = (size_t)(pl_fast_code_end - pl_fast_code_start);
```

不要写入 `pl_fast_code_start` 指向的区域，除非该区域本来就是可写 RAM 且你的设计明确允许写入。

## 6. 自动初始化为什么需要 section

传统启动代码常手工调用：

```c
clock_init();
uart_init();
sensor_init();
```

模块一多，集中列表容易遗漏。使用 `PL_INIT` 后，每个模块自注册，链接器将条目汇总。启动代码只遍历边界：

```c
for (entry = pl_app_init_start; entry < pl_app_init_end; ++entry) {
    entry->function();
}
```

顺序由 `PL_INIT` 的优先级组成的 section 名控制。建议固定三位或四位宽度，例如 `010`、`020`、`100`，使字符串排序与数值排序一致。
